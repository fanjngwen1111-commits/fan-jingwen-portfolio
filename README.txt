范静雯 · 视觉传达设计作品集

这是一个可在本地直接预览、也可部署到 GitHub Pages 的静态网站。页面使用原生 HTML、CSS 和 JavaScript；图片与视频保存在 assets 文件夹，并按需加载。

本地预览：保留 index.html 与 assets 文件夹的相对位置，双击 index.html 即可打开。请勿把视频或图片文件单独移出 assets。

部署：将 index.html 和 assets 文件夹一起上传到 GitHub 仓库根目录，再在 Settings → Pages 中选择 main 分支与根目录。

修改项目：项目名称、分类、简介位于 index.html 的 projects 数组；图片路径位于 MEDIA 对象；视频放在 assets 中，并通过 media-...Video 模板绑定。弹窗视频显示在项目长图前。

本地版本已新增天猫 KV、小野 IP 动态 KV、瑞雪迎年 KV，暂未上传 GitHub。
